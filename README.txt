BLASTTIER WEBSITE
=================
Upload index.html to a static host such as Cloudflare Pages.

Included:
- BlastTier branding
- Overall + Minecraft kits
- Player rankings and skins
- + Add Player button (no players pre-added)
- Add Kit / Add Tier
- Chat
- Search
- Responsive layout

No demo player is included. Add your own players from the + Add Player button.
Player data is stored in browser localStorage, so it is local to that browser.
